# LChatAi — GUI Super Skill

**Design only.** Telegram-inspired GUI reference skill: mobile and desktop layouts, light/dark themes, chat lists, conversation screens, settings, calls, media, states, design tokens, AI naming and microcopy. No AeroChat, no backend, no messenger implementation.
