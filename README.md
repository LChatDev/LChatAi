# LChatAi — GUI Super Skill

**GUI design only.** A Telegram-inspired visual skill with **10 individual SVG design references**, mobile and desktop layouts, light/dark themes, chats, profile, settings, calls, media, interface states, design tokens, AI naming, branding and microcopy. **No AeroChat, no backend or functional messenger.**

## Releasing

A manual-release GitHub Actions workflow is included at `.github/workflows/release.yml`. Run it using **Actions → Publish GUI Skill release → Run workflow**. This workflow packages the repository and creates a `v1.0.0` release if permitted by repository Actions settings. **No release is claimed until the workflow succeeds.**

## Rights and provenance

The ten SVGs are original custom mockup diagrams. The ten larger AI-generated PNG concept boards from the earlier chat package are **not uploaded to this repository**. These are unofficial references and not screenshots from Telegram. External project links are references, not copied third-party source trees. See [SOURCES.md](SOURCES.md).
